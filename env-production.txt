================================================================================
JOMS FRONTEND - PRODUCTION ENV
Frontend: https://kods.online
Backend API Gateway: https://api.kods.online
================================================================================

Use ONLY VITE_API_BASE_URL in production. Do NOT set VITE_AUTH_API_BASE_URL to
https://api.kods.online/auth — that double-prefixes paths like /auth/admin/login.

~/Joms-Frontend/.env  (used during docker build — keep minimal)
--------------------------------------------------------------------------------
VITE_API_BASE_URL=https://api.kods.online

~/Joms-Frontend/.env.production
--------------------------------------------------------------------------------
VITE_API_BASE_URL=https://api.kods.online

Resolved URLs (via nginx API gateway)
--------------------------------------------------------------------------------
Login:        https://api.kods.online/auth/admin/login
Admin APIs:   https://api.kods.online/admin/...
Services:     https://api.kods.online/services/...
Venues:       https://api.kods.online/venues/...
KYC:          https://api.kods.online/venue-kyc
Memberships:  https://api.kods.online/memberships
Settings:     https://api.kods.online/settings

Rebuild frontend on EC2 after changing .env:
  cd ~/Joms-Frontend
  docker build -t joms-frontend .
  docker rm -f joms-frontend || true
  docker run -d --name joms-frontend -p 80:80 joms-frontend
